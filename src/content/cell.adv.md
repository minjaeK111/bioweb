## 생명과학Ⅰ로 확장: 생물의 특성과 세포 분열

### 생물의 특성 7가지

| 특성 | 뜻 | 예 |
| --- | --- | --- |
| 세포로 구성 | 모든 생물은 세포로 이루어짐 | 단세포 생물, 다세포 생물 |
| 물질대사 | 효소를 이용해 물질을 합성·분해 | 광합성, 세포 호흡 |
| 자극에 대한 반응 | 환경 변화를 감지하고 반응 | 빛을 향해 자라는 식물 |
| 항상성 | 몸속 환경을 일정하게 유지 | 체온 36.5 ℃ 유지 |
| 발생과 생장 | 수정란 → 개체, 세포 수 증가 | 올챙이 → 개구리 |
| 생식과 유전 | 자손을 만들고 형질을 물려줌 | 부모 닮은 자식 |
| 적응과 진화 | 환경에 알맞게 변해 감 | 사막 여우의 큰 귀 |

**바이러스**는 유전 물질(DNA 또는 RNA)과 단백질 껍질로만 되어 있고 세포 구조가 없다. 스스로 물질대사를 못 해 **숙주 세포 안에서만 증식**한다. 그래서 생물과 무생물의 중간 특성을 가진다.

### 생명 과학의 탐구 방법

- **귀납적 탐구**: 관찰 → 자료 수집 → 규칙성 발견 → 결론. 예) 구달의 침팬지 관찰.
- **연역적 탐구**: 관찰 → 문제 인식 → **가설** → 탐구 설계 및 수행 → 결과 분석 → 결론.
  - **대조군**: 조건을 바꾸지 않은 집단. **실험군**: 조건을 바꾼 집단.
  - **조작 변인**(일부러 바꾸는 것), **통제 변인**(같게 유지하는 것), **종속 변인**(결과로 측정하는 것).

### 염색체

- **염색체**는 DNA가 **히스톤 단백질**에 감겨 뭉친 것이다. DNA + 히스톤 = **뉴클레오솜** 단위.
- 세포 분열 때만 막대 모양으로 응축되어 보이고, 평소에는 풀어진 **염색사** 상태다.
- 복제된 염색체는 **염색 분체** 2개가 동원체에서 붙어 있다. 두 염색 분체의 유전 정보는 같다.
- **상동 염색체**: 모양과 크기가 같은 염색체 한 쌍. 하나는 아버지, 하나는 어머니에게서 온다.
- 사람의 체세포: **2n = 46** (상염색체 22쌍 + 성염색체 1쌍). 여자 XX, 남자 XY.
- **핵형**: 염색체의 수, 모양, 크기를 정리한 것. 핵형 분석으로 염색체 이상을 알 수 있다.

### 세포 주기와 세포 분열

세포 주기 = **간기(G1 → S → G2)** + **분열기(M기)**

- G1기: 세포 생장, 단백질 합성
- **S기: DNA 복제** (DNA 양이 2배)
- G2기: 분열 준비
- M기: 핵분열(전기·중기·후기·말기) + 세포질 분열

**체세포 분열**: 2n → 2n, 1회 분열, 딸세포 2개. 생장과 재생에 쓰인다.

**감수 분열**(생식세포 형성): 2n → n, 연속 2회 분열, 딸세포 4개.

| 구분 | 체세포 분열 | 감수 분열 |
| --- | --- | --- |
| 분열 횟수 | 1회 | 2회 |
| 딸세포 수 | 2개 | 4개 |
| 염색체 수 | 2n → 2n | 2n → n |
| 상동 염색체 접합 | 없음 | **감수 1분열에서 2가 염색체 형성** |
| 역할 | 생장, 재생 | 생식세포 형성 |

감수 1분열 전기에 상동 염색체 사이에서 **교차**가 일어나고, 중기에 상동 염색체가 무작위로 배열되어 **유전적 다양성**이 생긴다.

> 핵심 한 줄: 염색체는 DNA의 포장이고, 체세포 분열은 복사, 감수 분열은 절반으로 나눠 다양성을 만든다.
