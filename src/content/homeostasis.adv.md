## 생명과학Ⅰ: 항상성과 몸의 조절

### 신경계

**중추 신경계** = 뇌 + 척수

| 부위 | 기능 |
| --- | --- |
| 대뇌 | 감각·운동·기억·언어·판단 (좌우 교차 지배) |
| 소뇌 | 몸의 균형, 운동 조절 |
| 간뇌 | 시상(감각 중계), **시상 하부**(체온·혈당·삼투압 조절, 자율 신경·호르몬의 중추) |
| 중간뇌 | 눈의 움직임, 동공 반사 |
| 연수 | 심장 박동, 호흡, 소화 조절, 재채기·침 분비 반사 |
| 척수 | 뇌와 말초 사이 신호 통로, **무릎 반사** 등 |

**말초 신경계**

- **체성 신경계**: 의식적 운동 (골격근)
- **자율 신경계**: 무의식적 조절 (내장, 혈관). **교감 신경**(긴장·위급: 심박 ↑, 동공 확대, 소화 ↓)과 **부교감 신경**(안정: 심박 ↓, 소화 ↑)이 반대로 작용(길항 작용).

### 호르몬

**내분비샘**에서 만들어져 **혈액**으로 운반되고, 특정 **표적 기관**에만 작용한다. 신경보다 느리지만 효과가 오래간다.

| 내분비샘 | 호르몬 | 작용 |
| --- | --- | --- |
| 뇌하수체 전엽 | 생장 호르몬, TSH, ACTH | 생장, 다른 내분비샘 자극 |
| 뇌하수체 후엽 | **항이뇨 호르몬(ADH)** | 콩팥 물 재흡수 ↑ |
| 갑상샘 | **티록신** | 물질대사 ↑, 체온 ↑ |
| 이자 | **인슐린** / **글루카곤** | 혈당 ↓ / 혈당 ↑ |
| 부신 속질 | 에피네프린 | 혈당 ↑, 심박 ↑ (교감 신경과 협력) |
| 부신 겉질 | 코르티코이드 | 혈당 ↑, 무기염류 조절 |

### 항상성 조절의 실제

**혈당 조절**

- 혈당 ↑ (식후) → 이자 β세포 → **인슐린** → 간에서 포도당 → 글리코젠 합성, 세포의 포도당 흡수 ↑ → 혈당 ↓
- 혈당 ↓ (공복) → 이자 α세포 → **글루카곤** → 글리코젠 → 포도당 분해 → 혈당 ↑
- 당뇨병: 1형(인슐린을 못 만듦), 2형(인슐린에 반응이 둔함)

**체온 조절** (시상 하부)

- 추울 때: 교감 신경 → 피부 혈관 수축(열 손실 ↓), 골격근 떨림·티록신 ↑(열 발생 ↑)
- 더울 때: 피부 혈관 확장, 땀 분비 ↑

**삼투압 조절**: 체액 농도 ↑ → 시상 하부 → 뇌하수체 후엽 **ADH** ↑ → 콩팥 물 재흡수 ↑ → 오줌 양 ↓, 진해짐.

### 방어 작용 (면역)

**비특이적 방어**: 병원체 종류를 가리지 않음. 피부·점막, 눈물·침의 라이소자임, **식세포 작용**(백혈구), **염증 반응**(모세 혈관 확장, 붓고 빨개짐).

**특이적 방어**: 특정 **항원**을 인식하는 **림프구**가 담당.

| 면역 | 세포 | 방식 |
| --- | --- | --- |
| 체액성 면역 | **B 림프구** → 형질 세포 | **항체** 분비 → 항원과 결합(항원 항체 반응) |
| 세포성 면역 | **T 림프구**(세포독성 T) | 감염된 세포를 직접 파괴 |

- 보조 T 림프구가 B 림프구를 활성화해 두 면역이 함께 작동한다.
- **1차 면역 반응**: 처음 침입. 항체가 천천히, 적게 생김. 일부 B 세포가 **기억 세포**로 남음.
- **2차 면역 반응**: 같은 항원 재침입. 기억 세포가 빠르고 많은 항체를 만듦 → 병에 걸리지 않거나 가볍게 앓음.
- **백신**: 약화·죽인 병원체나 항원 조각을 넣어 1차 면역 반응을 미리 일으켜 **기억 세포**를 만들어 두는 것.
- **혈액형 응집**: 적혈구의 응집원(항원 A, B)과 혈장의 응집소(항체 α, β)가 만나면 응집. O형 혈장에는 α, β 둘 다 있다.
- 알레르기(과민 반응), 자가 면역 질환(자기 세포 공격), 에이즈(HIV가 보조 T 림프구 파괴 → 면역 결핍).

> 핵심 한 줄: 신경(빠름)과 호르몬(오래감)이 시상 하부를 중심으로 몸을 되돌리고, 면역은 기억 세포로 두 번째 침입을 막는다.
